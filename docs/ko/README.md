# Competitive Taiko Rating (C-Rating)

**Languages:** [한국어](./README.md) | [日本語](../ja/README.md) | [English](../../README.md)

태고의 달인 온라인 대회 성적을 기반으로 유저의 상대적 실력을 정밀하게 산정하는 **C-Rating (Competitive Rating)** 시스템입니다. 본 문서는 C-Rating의 핵심 알고리즘과 레이팅 산출 로직에 대해 상세히 설명합니다.

본 프로젝트는 개인이 운영하는 팬 서비스이며, 주식회사 반다이 남코 엔터테인먼트와는 아무런 관련이 없습니다.

---

## 📋 프로젝트 개요
C-Rating은 실제 대회에서의 **순위와 점수**를 바탕으로 유저 간의 상대적 우위를 평가합니다.

*   **P-Rating (Performance Rating)**: 곡별 최고 기록을 기반으로 산정하는 절대적 실력 지표.
*   **C-Rating (Competitive Rating)**: [동더히로바(Donderhiroba)](https://donderhiroba.jp) 온라인 대회의 실제 경기 결과를 바탕으로 산정하는 상대적 실력 지표.

---

## 📈 레이팅 산출 알고리즘
C-Rating은 체스, 바둑 등에서 널리 사용되는 **Glicko-2** 알고리즘을 태고의 달인 환경에 맞게 최적화하여 사용합니다.

### 1. 경기 결과 처리 (Glicko Score)
단순한 승패(1 또는 0) 대신, 두 플레이어의 점수 비중을 활용하여 경기 결과를 수치화합니다.
$$Score = \frac{MyTotalScore}{MyTotalScore + OpponentTotalScore}$$
이 방식은 근소한 점수 차이로 패배했을 때와 큰 점수 차이로 패배했을 때의 레이팅 변동을 차등화하여 더욱 정밀한 실력 반영을 가능케 합니다.

### 2. 매치메이킹 및 상대 선정
모든 참가자를 대상으로 레이팅을 업데이트하되, 계산 효율성과 정확성을 위해 각 플레이어별로 **최대 20명의 상대**를 선정하여 매치를 시뮬레이션합니다.
*   레이팅이 유사한 상위 10명과 하위 10명을 우선적으로 매칭합니다.
*   참가자 수가 적을 경우(21명 이하) 모든 참가자와의 경기를 반영합니다.

### 3. 레이팅 구성 요소
*   **Rating**: 플레이어의 실력을 나타내는 중심값 (초기값: 1500)
*   **RD (Rating Deviation)**: 레이팅의 신뢰도를 나타내는 편차. 값이 작을수록 레이팅이 정확함을 의미하며, 경기에 참여하지 않으면 시간이 지남에 따라 증가합니다. (초기값: 350, 최대값: 350)
*   **Volatility**: 플레이어의 실력 일관성을 나타내는 변동성.

### 4. 미참여 유저 처리 (RD Decay)
세션에 참여하지 않은 유저의 실력 추정 불확실성을 반영하기 위해 다음과 같은 처리를 수행합니다.
*   세션 미참여 시 RD 값이 증가하여 다음 참여 시 레이팅 변동 폭이 커집니다.
*   참여하지 않은 세션당 레이팅 점수가 소폭 감소(현재 -10점)하여 활동성을 장려합니다.

---

## 🏆 세션 운영 방식
*   **세션 주기**: 5일 단위로 새로운 세션이 시작됩니다.
*   **곡 선정**: 각 세션마다 랜덤하게 지정된 곡들로 대회가 구성됩니다.
*   **자동 집계**: 동더히로바 대회에 기록을 남기면 세션 종료 후 서버에서 자동으로 레이팅을 계산하여 업데이트합니다.
