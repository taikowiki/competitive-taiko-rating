# 서비스 안내

## 소개
본 서비스는 [동더히로바(Donder Hiroba)](https://donderhiroba.jp)의 대회 기록을 기반으로 태고의 달인 유저의 실력을 수치화하여 레이팅 정보를 제공합니다. 본 서비스는 개인이 운영하는 팬 서비스이며, 주식회사 반다이 남코 엔터테인먼트와는 아무런 관련이 없습니다.

## 참여 방법
1. [메인 페이지](https://crating.taiko.wiki)에서 현재 진행 중인 동더히로바 대회를 확인합니다.
2. 해당 대회에 참가하여 기록을 남깁니다.
3. 세션 종료 후, 남겨진 기록을 바탕으로 레이팅이 자동으로 계산 및 업데이트됩니다.

## 운영 규칙
- **시즌 및 세션**: 하나의 시즌은 여러 개의 세션으로 구성됩니다.
- **세션 기간**: 각 세션은 5일 동안 진행되며, 종료 직후 다음 세션이 시작됩니다.
- **참가 인정**: 세션 기간 내 개최된 동더히로바 대회 중 하나 이상에 참여하면 해당 세션에 참가한 것으로 간주됩니다.
- **레이팅 업데이트**: 세션 종료 시 모든 대회 결과를 집계합니다. 레이팅이 유사한 최대 20명의 유저와 점수를 비교하여 레이팅을 산출하며, **Glicko-2** 알고리즘을 사용합니다.
- **레이팅 변동**: 세션에 참여하지 않을 경우 레이팅이 소폭 감소하며, 실력 추정의 불확실성을 나타내는 **레이팅 편차(RD, Rating Deviation)** 점수가 증가할 수 있습니다.
- **곡 구성**: 매 세션마다 곡이 무작위로 선정됩니다. 곡 풀(Song Pool)은 시즌 단위로 변경될 수 있습니다.
